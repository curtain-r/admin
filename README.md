# 项目 README

这是一个基于 **Vite + TypeScript** 的前端项目模板。

## 环境要求

- Node.js 18 及以上版本
- Yarn（推荐）或 npm

## 安装依赖

```bash
yarn
```

## 本地开发

```bash
yarn dev
```

启动后可在终端提示的本地地址访问页面。

## 打包构建

```bash
yarn build
```

## 预览构建结果

```bash
yarn preview
```

## 目录说明

- `src/`：业务源码目录
- `public/`：静态资源目录
- `index.html`：应用入口 HTML
